Conditional Statements (if/else)

Conditional statements are used to make decisions in Smali code. They check if something is true or false and execute different code based on the result.

🎯 Why this is important for modding:
Most premium features are protected by if statements that check:
✅ if user is VIP → show premium
❌ if user is NOT VIP → show ads

By reversing or removing these checks, you can unlock everything!

Common Conditional OpCodes:

OpCodeConditionWhen it jumps
if-eqz if equals zero When register == 0
if-nez if not equals zero When register != 0
if-eq if equal When vA == vB
if-ne if not equal When vA != vB
if-gt if greater than When vA > vB
if-lt if less than When vA < vB
if-ge if greater or equal When vA >= vB
if-le if less or equal When vA <= vB
goto unconditional Always jumps
🔥 Pro Modding Trick:
Change if-eqz to if-nez to reverse the logic!

Original: if-eqz v0, :not_vip # if NOT VIP, show ads
Modified: if-nez v0, :not_vip # if IS VIP, show ads (reversed!)

Or simply remove the check entirely by replacing with goto!

Example: VIP check in Smali

# Method: checkVIP() returns String .method public checkVIP()Ljava/lang/String; .locals 2 .prologue # Get the VIP status field iget v0, p0, Lcom/example/User;-is_vip:Z # If v0 == 0 (not VIP), jump to :not_vip if-eqz v0, :not_vip # User IS VIP const-string v1, "Welcome VIP User! 🎉" return v1 :not_vip # User is NOT VIP const-string v1, "Please upgrade to VIP" return v1 .end method
💡 How to mod this:
Option 1: Change if-eqz v0, :not_vip to if-nez v0, :not_vip
Option 2: Change the field value: const/4 v0, 0x0 to const/4 v0, 0x1
Option 3: Remove the check entirely and always return VIP message!

Another Example: Level Check

# Check if user level is high enough iget v0, p0, Lcom/example/User;-level:I # If level >= 10, show premium const/16 v1, 0xA # 10 if-ge v0, v1, :premium # Not high enough const-string v2, "Level 10 required" return v2 :premium const-string v2, "Premium Unlocked!" return v2
⚡ Quick Mod:
Change if-ge v0, v1, :premium to goto :premium
This will always go to the premium section, bypassing the level check! ✅

Working with Methods

In Lesson 5, we'll learn about calling methods in Smali. This is how you call functions from other classes.

# Calling a method: getUserLevel() invoke-virtual {p0}, Lcom/example/User;-getLevel()I move-result v0 # Now v0 holds the user level!
📌 Key OpCodes:
invoke-virtual → Call a method
invoke-static → Call a static method
move-result → Get the return value
move-result-object → Get an object return value
