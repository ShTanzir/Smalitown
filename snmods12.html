Static vs Non-Static Methods

In Smali, methods come in two flavors: static and non-static. Understanding the difference is crucial for calling methods correctly.

⚡ What's the Difference?
🔹 Static methods: Belong to the class, not to an object. Called with invoke-static.
🔹 Non-static methods: Belong to an object. Called with invoke-virtual, invoke-direct, etc.

💡 Key Rule: In non-static methods, p0 is always this (the object itself)!

1. Non-Static (Instance) Methods:

# Non-static method: belongs to an object .method public getLevel()I .locals 1 .prologue # p0 is "this" (the object itself) iget v0, p0, Lcom/example/User;-level:I return v0 .end method # Calling a non-static method invoke-virtual {v0}, Lcom/example/User;-getLevel()I move-result v1
🔥 Important:
In non-static methods, p0 is the object reference (this).
This means you always need an object to call a non-static method!

2. Static Methods:

# Static method: belongs to the class .method public static getMaxLevel()I .locals 1 .prologue # No p0! Static methods don't have "this" const/16 v0, 0x64 # 100 return v0 .end method # Calling a static method invoke-static {}, Lcom/example/User;-getMaxLevel()I move-result v0
💡 Pro Tip:
When modding, look for the static keyword in the method definition.
If you see .method public static, it's a static method!
If you see .method public (without static), it's non-static.

⚡ Quick Mod Example:
If you find a static method called isLicenseValid()Z:
Change const/4 v0, 0x0 to const/4 v0, 0x1

This will make the license check always return TRUE! ✅
