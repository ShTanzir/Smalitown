Working with Fields (Variables)

Fields are variables in Smali that store data. There are two types:
🔸 Instance fields → Belong to an object (each object has its own copy)
🔸 Static fields → Belong to the class (shared across all objects)

📦 Why fields matter for modding:
Fields store coins, lives, health, scores, VIP status, and more. By reading and modifying fields, you can change anything in the game or app!

Field Access OpCodes:

OpCodePurposeExample
igetRead instance fieldiget v0, p0, Lcom/example/Game;->coins:I
iputWrite instance fieldiput v0, p0, Lcom/example/Game;->coins:I
sgetRead static fieldsget v0, Lcom/example/Game;->MAX_LEVEL:I
sputWrite static fieldsput v0, Lcom/example/Game;->MAX_LEVEL:I
iget-objectRead object fieldiget-object v0, p0, Lcom/example/User;->name:Ljava/lang/String;
iput-objectWrite object fieldiput-object v0, p0, Lcom/example/User;->name:Ljava/lang/String;
sget-objectRead static objectsget-object v0, Lcom/example/Game;->INSTANCE:Lcom/example/Game;
sput-objectWrite static objectsput-object v0, Lcom/example/Game;->INSTANCE:Lcom/example/Game;
🔥 Modding Example 1: Unlimited Coins
Find iget v0, p0, Lcom/example/Game;->coins:I and modify it:
const/16 v0, 0x2710 # 10000 coins
Then replace iget with this to set coins to 10000!

Example: Reading a Field

# Read coins from Game object iget v0, p0, Lcom/example/Game;-coins:I # v0 now contains the coin value
💡 Pro Tip:
Look for fields with names like coins, score, level, health, lives, is_vip, has_premium. These are your gold mines for modding!

Example: Writing to a Field

# Set coins to 9999 const/16 v0, 0x270F # 9999 iput v0, p0, Lcom/example/Game;-coins:I
⚡ Another Example: Unlocking VIP
const/4 v0, 0x1
iput v0, p0, Lcom/example/User;->is_vip:Z

This sets the VIP status to TRUE! ✅
