Basic OpCodes (Instructions)

OpCodes (Operation Codes) are the instructions in Smali that tell the device what to do. Think of them as commands like "load this value" or "return this result".

⚡ Why OpCodes matter for modding:
When you want to unlock VIP, remove ads, or change behavior, you're essentially modifying OpCodes! For example, changing const/4 v0, 0x0 to const/4 v0, 0x1.

Essential OpCodes for Beginners:

OpCodePurposeExample
const/4 Load a 4-bit value (range: -8 to 15) const/4 v0, 0x1
const/16 Load a 16-bit value const/16 v1, 0x64
const Load any 32-bit value const v2, 0x3E8
const-string Load a string const-string v3, "Hello"
move Copy value from one register to another move v4, v0
return Return a value from a method return v0
return-void Return nothing (void method) return-void
if-eqz If register equals zero, jump to label if-eqz v0, :cond_1
if-nez If register is not zero, jump to label if-nez v0, :cond_1
goto Unconditional jump to label goto :label_1
🔥 Real Modding Example:
Original: const/4 v0, 0x0 # false
Modified: const/4 v0, 0x1 # true ✅

This simple change can unlock VIP, enable pro features, or bypass purchases!

Example: A complete method in Smali

# A method that returns true if user is VIP .method public isVip()Z .locals 1 .prologue # Load 0x1 (true) into v0 const/4 v0, 0x1 # Return the value return v0 .end method # This will always return TRUE!
💡 Pro Tip:
When searching for premium features, look for methods that return Z (boolean). If you see const/4 v0, 0x0 followed by return v0, that's your target!

In Lesson 4, we'll learn about conditional statements in Smali. These are used to make decisions in the code.

# Example: Check if user is VIP iget v0, p0, Lcom/example/User;-is_vip:Z # If v0 == 0 (false), jump to :cond_not_vip if-eqz v0, :cond_not_vip # User IS VIP! Show premium features const-string v1, "Welcome VIP!" return v1 :cond_not_vip # User is NOT VIP const-string v1, "Upgrade to VIP" return v1

Change if-eqz to if-nez to reverse the logic! This is a common trick to unlock premium features.
