Arrays & Lists

Arrays are collections of data. In Smali, they're used for everything from player inventories, item lists, level data, leaderboards, and more.

📊 Why arrays matter for modding:
Arrays often store items, rewards, high scores, and unlocked content. By modifying arrays, you can unlock all items, max out scores, or give yourself rare rewards!

Array OpCodes:

OpCodePurposeExample
new-arrayCreate a new arraynew-array v0, v1, [I
array-lengthGet array sizearray-length v0, v1
agetRead array elementaget v0, v1, v2
aputWrite array elementaput v0, v1, v2
aget-objectRead object arrayaget-object v0, v1, v2
aput-objectWrite object arrayaput-object v0, v1, v2
fill-array-dataFill array with datafill-array-data v0, :array_data
🔥 Modding Example: Unlock All Items
Find an array that stores unlocked items. Look for aput or new-array.
You can increase the array size or fill it with values to unlock everything!

Example: Creating & Using an Array

# Create int[5] array const/4 v0, 0x5 # size = 5 new-array v1, v0, [I # v1 = array # Set array[0] = 100 const/16 v2, 0x64 # 100 const/4 v3, 0x0 # index 0 aput v2, v1, v3 # Read array[0] aget v4, v1, v3 # v4 now contains 100
💡 Pro Tip:
Look for array-length used in loops. This is often a game loop that processes items.
Modify array-length or the loop condition to access out-of-bounds items!

Example: Loop Through an Array

# Loop through items array array-length v0, v1 # v0 = array length const/4 v2, 0x0 # i = 0 :loop_start if-ge v2, v0, :loop_end # Process array[v2] aget v3, v1, v2 # Do something with v3... # i++ add-int/lit8 v2, v2, 0x1 goto :loop_start :loop_end
⚡ Common Mod: Unlimited Inventory
Find where items are added to inventory (look for aput or invoke to add methods).
Increase the array size or skip the size check to store unlimited items!
