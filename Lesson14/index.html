Math & Calculations

Mathematical operations are everywhere in apps - score calculations, damage formulas, coin additions, timer logic, and more. In Smali, these are done with math OpCodes.

🧮 Why math matters for modding:
Math controls game mechanics, reward systems, leveling, and in-app purchases. By modifying calculations, you can give yourself infinite resources, max stats, or unlock everything!

Math OpCodes:

OpCodeOperationExample
add-intAdditionadd-int v0, v1, v2
add-int/lit8Add with literaladd-int/lit8 v0, v1, 0x5
sub-intSubtractionsub-int v0, v1, v2
mul-intMultiplicationmul-int v0, v1, v2
div-intDivisiondiv-int v0, v1, v2
rem-intRemainder (mod)rem-int v0, v1, v2
neg-intNegateneg-int v0, v1
🔥 Modding Example: Infinite Coins
Find the code that adds coins to your balance.

Original: add-int v0, v1, v2
Modified: const/16 v0, 0x2710 # 10000 coins

Now you always get 10000 coins instead of the normal amount! ✅

Common Math Modding Scenarios:

# 1. Score multiplier # Original: multiply score by 1 mul-int v0, v1, v2 # Change to multiply by 100: mul-int/lit8 v0, v1, 0x64 # 2. Unlimited health # Original: health = health - damage sub-int v0, v1, v2 # Change to: health = health + damage (heal instead of hurt!) add-int v0, v1, v2 # 3. Level up requirement # Original: if (experience > maxExp) level++ if-le v0, v1, :no_level_up # Change to: always level up! goto :level_up
💡 Pro Tip:
Look for math operations in game loops, reward functions, and shop systems.
Common targets:
🔹 add-int → Look for coin/score additions
🔹 sub-int → Look for health/damage reductions
🔹 mul-int → Look for multipliers or percentages
🔹 div-int → Look for divisions (often used in leveling)

Floating Point Math (for float/double values):

# Float operations (for values with decimals) add-float v0, v1, v2 sub-float v0, v1, v2 mul-float v0, v1, v2 div-float v0, v1, v2 # Double operations (more precise) add-double v0, v2, v4
⚡ Quick Mod:
Find any add-int or mul-int in the app.
Change the result to a much larger value.
For example: const/16 v0, 0x3E7 (999) instead of the calculated value.

This gives you massive amounts of whatever the app is calculating! 🚀
