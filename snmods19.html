📖 Lesson 19

Project 1: Modding a Simple App

This is it! Time to apply everything you've learned!
We'll mod a simple app step by step, from decompilation to testing.

🎯 Project Goals:
🔹 Mod a simple calculator/utility app with premium features
🔹 Unlock all premium features
🔹 Remove ads and limitations
🔹 Learn the complete modding workflow

Step 1: Choose Your Target

📱 Recommendation:
Start with a simple app that has premium features:
🔸 A calculator with extra functions locked behind premium
🔸 A photo editor with filters locked
🔸 A game with levels or characters locked

Avoid apps with heavy obfuscation or root detection for your first project!

Step 2: Decompile the App

# Using APKTool apktool d target_app.apk # The decompiled files will be in a folder named "target_app" # Look for the "smali" folder
💡 Tip:
Use JADX to see the Java code alongside the Smali code.
This helps you understand what the app is doing!

Step 3: Find the Premium Feature

# Search for keywords in the smali folder grep -r "is_premium" smali/ grep -r "is_vip" smali/ grep -r "has_pro" smali/ # You might find something like this: Lcom/example/PremiumManager;->isPremium()Z
🔍 What to look for:
🔸 Methods that return Z (boolean)
🔸 Methods with names like isPremium, hasPro, checkLicense
🔸 Fields with names like premium, vip, unlocked
🔸 Conditional checks (if-eqz, if-nez) that check these values

Step 4: Apply the Patch

# Found: PremiumManager.smali .method public isPremium()Z .locals 1 .prologue # Original: returns a value from SharedPreferences iget v0, p0, Lcom/example/PremiumManager;-is_premium:Z return v0 .end method # PATCH: Force return true .method public isPremium()Z .locals 1 .prologue const/4 v0, 0x1 # ✅ ALWAYS TRUE! return v0 .end method
⚡ Alternative Patches:
If you can't find the method, try:
🔸 Modify the field in the constructor
🔸 Change the condition that checks the field
🔸 Search for the string that appears when locked

Example: Search for "Upgrade to Premium" and trace back to the check!

Step 5: Rebuild and Sign

# Rebuild the APK apktool b target_app -o mod_app.apk # Sign the APK (use your own keystore) jarsigner -verbose -sigalg SHA1withRSA -digestalg SHA1 -keystore my.keystore mod_app.apk alias_name # Or use APK Signer for easier signing apksigner sign --ks my.keystore mod_app.apk

Step 6: Test the Mod

✅ Testing Checklist:
🔸 Install the modded APK
🔸 Open the app and check if premium features are unlocked
🔸 Check if ads are removed (if that was your goal)
🔸 Test all features to ensure they work
🔸 If something doesn't work, go back to Step 3 and refine your patch
🎉 Congratulations!
You've just modded your first app! 🔥

Remember: Practice makes perfect. Keep trying different apps and techniques.
Every mod is a learning experience!
